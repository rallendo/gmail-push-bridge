Instant Gmail Push for Apple Mail

Gmail Push Bridge maintains a persistent, low-power IMAP IDLE connection to Google, triggering Apple Mail the exact second a new email arrives in your inbox.

OAuth Setup Guide (2 min) View on GitHub
⚡️

Real-Time IMAP IDLE

Uses Apple's Network.framework over TLS with TCP keepalives to listen directly for new email events with near-zero battery and CPU footprint.

🔒

100% Local & Private

No remote servers, no analytics, no intermediate proxies. Credentials and OAuth tokens are stored exclusively in your hardware-protected macOS Keychain.

🔑

Modern Authentication

Supports Sign in with Google (OAuth 2.0 with PKCE and Touch ID / Passkeys via SASL XOAUTH2) as well as traditional Google App Passwords.

🍎

Seamless Apple Mail Integration

Automatically pauses IMAP IDLE when Mail quits and reconnects with an immediate catch-up fetch when Mail opens, avoiding unnecessary background connections or unexpected popups.

🌙

Sleep & Wake Aware

Automatically detects system sleep, wake events, and network transitions, instantly refreshing the IMAP socket upon reconnection.

📖

Open Source Transparency

Licensed under the permissive MIT license. Completely open and auditable source code available on GitHub.
