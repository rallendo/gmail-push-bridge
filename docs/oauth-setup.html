Google OAuth 2.0 Setup (BYOC)

Set up your own private Google Cloud Desktop Client ID in under 2 minutes. Free, zero external dependencies, and 100% private to you.

Time Required ~2 Minutes
Cost $0 (Free Tier)
Privacy 100% Local Device Storage
1
Create a Free Google Cloud Project
  1. Open the Google Cloud New Project Page ↗
  2. Name the project Gmail Push Bridge (or any name you prefer).
  3. Leave Organization as No organization.
  4. Click Create and wait a few seconds.
2
Enable the Gmail API
  1. Go directly to the Gmail API Library Page ↗
  2. Make sure your newly created project is selected in the top bar.
  3. Click Enable.
3
Configure OAuth Consent Screen
  1. Navigate to OAuth Consent Screen ↗
  2. Select External, then click Create.
  3. Fill out only the 3 basic fields:
    • App name: Gmail Push Bridge
    • User support email: Choose your email from the dropdown.
    • Developer contact email: Enter your email.
  4. Click Save and Continue on the App Information page.
  5. Click Save and Continue on the Scopes page (the app requests IMAP dynamically).
  6. Under Test users, click + Add Users, enter your Gmail address, and click Add.
  7. Click Save and Continue, then click Back to Dashboard.
💡 Note on Publishing Status: Leave the project in Testing mode. Because you added your email as a Test User, you get immediate access with no audits or verification needed.
4
Create Desktop OAuth Credentials
  1. Go to Credentials Dashboard ↗
  2. At the top, click + Create Credentials → OAuth client ID.
  3. Under Application type, choose Desktop app.
  4. Name it Gmail Push Bridge Desktop (or default) and click Create.
  5. In the popup that appears, click Download JSON (or copy your Client ID & Secret).
5
Connect in Gmail Push Bridge
  1. Click the Gmail Push Bridge icon in your macOS Menu Bar → Settings & Status.
  2. Make sure Sign in with Google (OAuth 2.0) is selected.
  3. Click Import client_secret.json… and select the downloaded file (or paste your Client ID & Secret).
  4. Click Sign in with Google (Passkey / Browser).
  5. When Google opens in your browser:
    • Select your Google account.
    • If you see a screen saying "Google hasn't verified this app", click Advanced → Go to Gmail Push Bridge (unsafe). (This appears because your private project is in Testing mode).
    • Click Continue to authorize.
🎉 You're done! The status indicator will switch to green (IDLE active). Your Mac is now receiving instant Gmail push triggers directly into Apple Mail.
